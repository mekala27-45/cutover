name: explain-a-triage
description: Explain a Cutover receipt using its recorded decision, release and evidence without inventing model behavior.
---

Read packages/core and packages/cascade for the schema and priority rules. Use a receipt supplied by the user or an authorized database lookup. Explain the action, suggested queue, reason code and release digest. Distinguish guard-only from model inference. Never claim that a score establishes vehicle safety or that a complaint was closed. Do not expose the client digest, credentials, or raw narrative. Link relevant criterion evidence and say when it is absent.
